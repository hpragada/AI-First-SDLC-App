Keyboard journeys

Reported, never blocking

Eight things cannot be judged from a page standing still — whether focus can get out of a menu, whether you can see where you are, whether a screen reader is told when something changes. They can only be answered by operating the application with a keyboard. The industry scanner covers one of the eight.

The platform cannot discover your pages
It has no access to your application — that is deliberate. Tell it which addresses to visit and it will visit exactly those, and report on anything it was asked for and could not open.
Your pages Either format works. One path per line is enough. Paste a JSON list when you also want to give each page a name, say whether it is in scope, or point a pattern at a real page: entries carrying path, with optional title, enabled (or in_scope) and example. A path no browser can open — /events/:id — needs the JSON form, because only it can carry the example page to visit. Anything we cannot read is named back to you, never silently dropped.

Importing is how a project starts. Adding or correcting one page afterwards is a row in the table, not a re-paste — see Edit one page below.
