Keyboard journeys

Reported, never blocking

Eight things cannot be judged from a page standing still — whether focus can get out of a menu, whether you can see where you are, whether a screen reader is told when something changes. They can only be answered by operating the application with a keyboard. The industry scanner covers one of the eight.

Add pages

i
The platform cannot discover your pages
It has no access to your application — that is deliberate. Tell it which addresses to visit and it will visit exactly those, and report on anything it was asked for and could not open.
One path per line A path on its own is enough. Add a name after two spaces if you want one — it is only used to make the report readable. Start a line with # to register a page but leave it out of scope.
Or paste a list your project already has Accepts a plain list of paths, or a list of objects carrying path with optional title and enabled. Anything else is rejected with the line that could not be read — never silently dropped.
